## Ответы на вопросы пользователя

### Q1: "для каждого бита инкрементируется указатель stream?"

**A**: ❌ НЕТ! Инкремент ТОЛЬКО для установленных битов.

```c
for (int bit = 0; bit < 8; bit++) {
    if (mask & (1 << bit)) {
        vram[bit] = *pixel_ptr++;  // ← ТОЛЬКО здесь!
    }
}
```

**Результат**: Исправлена документация, добавлены пояснения.
