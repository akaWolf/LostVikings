## Технические детали

### Структура VGA данных

```cpp
struct myDrawInfoS_orig {
    uint8_t drawBuffer[65536*4];  // Planar VGA память
    SDL_Color drawPalette[256];   // Палитра
    uint32_t myOffset;            // Offset для прокрутки
    uint8_t myPixelOffset;        // Pixel offset
};
```

### Формат planar VGA

```
drawBuffer[offset * 4 + 0] = plane 0 (bit 0 цвета)
drawBuffer[offset * 4 + 1] = plane 1 (bit 1 цвета)
drawBuffer[offset * 4 + 2] = plane 2 (bit 2 цвета)
drawBuffer[offset * 4 + 3] = plane 3 (bit 3 цвета)

offset = y * 320 + x
color = (plane3 << 3) | (plane2 << 2) | (plane1 << 1) | plane0
```

### Копирование данных (render_v2_test.cpp)

```cpp
void render_callback_v2(void* state)
{
    if (!myDrawInfo_v2 || !myDrawInfo) return;
    
    // Копируем VGA память
    memcpy(myDrawInfo_v2->drawBuffer, myDrawInfo->drawBuffer, 65536*4);
    
    // Копируем палитру
    memcpy(myDrawInfo_v2->drawPalette, myDrawInfo->drawPalette, 256 * sizeof(SDL_Color));
    
    // Копируем offset
    myDrawInfo_v2->myOffset = myDrawInfo->myOffset;
    myDrawInfo_v2->myPixelOffset = myDrawInfo->myPixelOffset;
}
```

## Проблемы которые были решены

### 1. ❌ → ✅ Конфликт обработки событий
**Проблема**: SDL_PollEvent() глобальный, оба окна конкурировали за события  
**Решение**: Убрали SDL_PollEvent() из второго окна, используем общий need_quit

### 2. ❌ → ✅ Зависание клавиш
**Проблема**: Ввод работал некорректно, клавиши "залипали"  
**Решение**: Второе окно не обрабатывает клавиши вообще

### 3. ❌ → ✅ Ctrl-C не работал с первого раза
**Проблема**: Нужно было нажимать дважды  
**Решение**: Убрали event loop из второго окна

### 4. ❌ → ✅ Segfault при запуске
**Проблема**: Неправильное объявление структуры myDrawInfoS  
**Решение**: Используем точное совпадение с vikings.exe_seg000.cpp

### 5. ❌ → ✅ Segfault при копировании
**Проблема**: myDrawInfo ещё не инициализирован  
**Решение**: Проверка if (myDrawInfo) перед копированием
