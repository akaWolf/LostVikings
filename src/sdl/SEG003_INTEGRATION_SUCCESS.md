## Созданная функция

### `seg003_f9e_proc_sdl()`

```c
void seg003_f9e_proc_sdl(
    uint8_t* mask_stream,        // Маски (8 байт на строку)
    uint8_t* pixel_stream,       // Данные пикселей
    uint8_t* sdl_buffer,         // SDL linear buffer [y*344+x]
    int dest_x, int dest_y,      // Координаты назначения
    uint16_t width, uint16_t height
)
```

**Особенности:**
- ✅ Адаптирована для SDL linear формата (не planar VGA)
- ✅ Правильно обрабатывает маски (pixel_ptr++ только для установленных битов)
- ✅ Поддерживает прозрачность (пропускает пиксели где бит = 0)
- ✅ Работает с любыми размерами спрайтов (кратными 8 по ширине)

## Ключевые открытия

### 1. SDL формат НЕ planar VGA

SDL `drawBuffer` хранит **готовые индексы цветов** (0-255), а не отдельные биты planes:

```c
// НЕ planar:
drawBuffer[offset] = color_index;  // ✅ Правильно

// НЕ так:
drawBuffer[offset * 4 + plane] = bit;  // ❌ Неправильно для SDL
```

### 2. Размер буфера

- **Width**: 344 (не 320!) - `RENDER_WIDTH`
- **Height**: 240 (не 200!)
- **Offset**: `y * 344 + x`

### 3. Палитра игры

- **Самый яркий цвет**: индекс 17 = `RGB(252, 252, 164)` (желтоватый)
- **Черный**: индекс 0 или 255
- **Цвет 15**: `RGB(112, 136, 96)` (зеленоватый, не белый!)
