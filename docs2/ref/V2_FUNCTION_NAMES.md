# V2 function naming map (phase B, task #38)

Scheme: `v2_<meaning>_<orig-hex-addr>[_<variant>]` — the address suffix keeps
`grep sub_XXXXX`-ability; meaning is verified against the function BODY and
original asm (doc comments are NOT trusted — see feedback_docs_inaccurate).
`_v2` tail marks the production fx:: side-effect variant of an AIL routine.
v2_fntest_call_sub_* wrappers keep raw orig names by design (paired with
string unit names in the FNSELFTEST env dispatcher) and are excluded here.
