### Folded forms

* `self.f = X`, `[g] += X`, `if X == Y goto L` … — `acc = X` folded into the next statement (LVD_LANGUAGE.md, Statements).
* `switch X:` / `select X:` with `N -> L` cases — runs of field-loaded / literal-loaded compare-and-branch statements.
* `say partner=P dy=±N cmd=X id=ID edge=E` — the seven-statement speech-bubble idiom.
* `if X & M goto L` / `if !(X & M) goto L` — `acc = bit(1 & 0x1#00)` + the bit-test branch `if acc == / != bit(X & M)`; `if bit(X & M) == 0 goto L` / `!= 0` — the same with `acc = bit(0 & 0x1#00)` (four spellings, four opcode pairs); `call` forms alike.
* `if same_facing(partner) goto L` / `if !same_facing(partner) goto L` — `acc = bit(self.flags & 0x40)` + `if acc == / != bit(partner.flags & 0x40)`.
* `if A & B == A goto L` / `!= A` — `[0206] = A`, `[0206] &= B`, `if A == / != [0206] goto L`: every bit of A is (not) set in B (the switch words against the pool).
* `hurt partner event=K amount=A facing` — `partner.event = K`, `partner.event_arg = A`, `partner.event_arg = setbit(partner.event_arg, 0x8000, bit(self.flags & 0x40))`.
* `anim_by_viking erik=A, baleog=B, olaf=C goto L [fallthrough]` — `select self.anim_idx: 0 -> b, 2 -> c`, `anim A`, `goto L`, then the states `b: anim B; goto L` and `c: anim C; goto L` (or `anim C` falling through); the two side states are written by the compiler.
* `loop X:` — a state whose last statement is `goto X`; the header implies it.
* `func NAME:` with inner labels `  NAME:`; `call F(self.f = N, [g] = N, acc = X)` — Functions.

## Anim code

Under an `anim NAME:` header. Lists carry one value per sub-sprite (masked: per matching one).

| cmd | statement | operands | meaning |
|---|---|---|---|
| 00 | `frame += N` | 1 byte | advance every (masked: matching) sub-sprite by N frames (data offset += N*72) |
| 01 | `frame N, N, …` | a byte per sub-sprite | sub-sprite frame(s): data offset = base + N*72, one N per sub-sprite (masked: per matching one) |
| 02 | `sfx N vol V` | 2 bytes | play sequence N; V is the console's volume byte (the PC reads N only) |
| 03 | `goto L` | label (word) | jump |
| 04 | `skip N` | 1 byte | one dead byte |
| 05 | `call L` | label (word) | run another stream; its `return` comes back here |
| 06 | `return` | — | back to the continuation of the last `call` |
| 07 | `dx ±N` | 1 signed byte | masked: sub-sprite x += N; unmasked: the object's x velocity += N pixels |
| 08 | `x ±N, ±N, …` | a signed word per sub-sprite | sub-sprite x = object x + N, one per sub-sprite (signed) |
| 09 | `dy ±N` | 1 signed byte | masked: sub-sprite y += N; unmasked: the object's y velocity += N pixels |
| 0A | `y ±N, ±N, …` | a signed word per sub-sprite | sub-sprite y = object y + N, one per sub-sprite (signed) |
| 0B | `int3` | — | INT 3 (nothing) |
| 0C | `pal N, N, …` | a byte per sub-sprite | colour bank bits of the sprite flags: (N << 3) & 0x70, one N per sub-sprite (masked: gated) |
| 0D | `mask N` | 1 byte | sub-sprite class mask for the rest of this frame (0 = all) |
| 0E | `yield` | — | end of frame; the next tick continues here |
| 0F | `wait N` | 1 byte | end of frame for N ticks |
| 10 | `flip_x` | — | XOR 0x200 (x flip) on the sub-sprite flags |
| 11 | `flip_y` | — | XOR 0x400 (y flip) |
| 12 | `flip_xy` | — | XOR 0x600 (both) |
| 13 | `class N, N, …` | a byte per sub-sprite | set the sub-sprite classes, one per sub-sprite (masked: per matching one) |
| 14 | `sprite N` | 1 byte | decompress image N of the bank into the sub-sprite buffer (skipped when N is current) |
| 15 | `type N` | 1 byte | sprite type (renderer bits) and strip count from the type table |
| 16 | `skip N #16` | 1 byte | one dead byte (command 16, the same as 04) |
| 17 | `bank 0xNNNN` | word | sprite bank = chunk id N |

| 19 | `show` | — | AND 0x9FFF: drawn again |
| 1A | `stop` | — | the anim ends (anim pc = FFFF) |

## Palettes

Under a `palette NAME:` header: `rgb r, g, b` per colour (6-bit DAC values), the block an op 13 d9 statement copies.
